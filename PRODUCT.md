# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Goutham and readers exploring what open voice models make possible on a personal Mac.

## Product Purpose
Meeting Notes Lab is a working local transcription prototype with the persona of a polished meeting notebook. Its interface and educational content support a public repository, portfolio case study and educational LinkedIn post. The user pinned a meeting-notebook persona on 2026-11-06, then explicitly requested a working Create speech feature using the installed compact model.

## Operating Context
Runs locally on a 24 GB Apple M5 Mac. No hosted inference, account or API key. Source recordings and exports remain in the project. Source code will be prepared for GitHub; publication and visibility need the user's decision.

## Capabilities and Constraints
- Tap the microphone to start and stop. Optional six-second draft transcription; final transcript after stopping.
- Import audio or video; export TXT, phrase-timed SRT and JSON.
- Try a bundled synthetic sample through the actual local transcription engine.
- Speech generation uses the installed Realtime-0.5B model. Create speech provides text input, installed voice presets, generation progress, cancellation, playback and WAV export. Explore retains capability education.
- Do not download the two approximately 17 GB full ASR models.
- No verified speaker labels, word alignment, automatic summaries, calendar integration, meeting bot or system-audio capture.
- The user pinned a Wispr Flow-like meeting-notebook persona, without cloning branding or building the whole product.

## Product Principles
The working task comes first. Explain model capabilities with honest availability labels. Keep recordings local. Every advertised control works. Show actual microphone levels, never fake live data.
